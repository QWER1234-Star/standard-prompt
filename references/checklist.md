# 两道核验清单

口播里的第三步是「拿到结果先不用直接用，先让 AI 按你的要求自己检查一遍，之后再人工核查」。这里把「检查一遍」拆成可执行的清单，并划清两者的边界。

---

## 可复制的自检提示词

把下面这段原样发给 AI，替换方括号内容：

```
请对照下面的任务卡，逐条检查你刚才给出的结果，并输出一张打勾表。

任务卡：
【粘贴五要素任务卡】

检查项：
1. 任务：结果是否就是任务卡里那一件小事，没有顺带做别的？
2. 背景：是否只用了给定材料？有没有引入材料之外的事实？
3. 输出格式：段数、字数、结构、文件类型是否逐项满足？
4. 限制：每条限制逐条打勾，不满足的直接指出第几条。
5. 示例：语气、节奏、视觉是否贴近示例？偏离处标出来。
6. 编造检查：所有数字、日期、人名、引用、专有名词是否都有来源？没有的一律改成「待核实」，不要保留推测值。
7. 兜底：有没有该问却没问、直接自己填了的地方？

只做两件事：输出打勾表，然后按检查结果修订一次。不要解释过程，不要顺手加新内容。
```

---

## AI 自检清单（对齐任务卡）

| 组 | 检查项 | 不通过时 |
| --- | --- | --- |
| 任务 | 只交付了那一件小事 | 删掉额外产出，或另起一轮 |
| 背景 | 未引入材料外的事实 | 标「待核实」或删除 |
| 格式 | 段数 / 字数 / 结构 / 类型逐项核对 | 改到符合，不解释原因 |
| 限制 | 3–6 条逐条打勾 | 明确指出第几条没满足 |
| 示例 | 语气、节奏、视觉有参照 | 标注偏离处 |
| 未编造 | 数字、日期、引用、专名有来源 | 一律改「待核实」 |
| 兜底 | 该问的问了，没自己填 | 补问，不补答案 |

自检记录的输出格式：

```
自检记录
[OK] 任务：……
[OK] 背景：……
[!!] 格式：第 2 段超出 20 字，已压缩
[OK] 限制 1–3：……
[!!] 未编造：出现 1 处未标注来源的百分比，已改为「待核实」
修订：1 次
```

## 人工核查清单（真实性由人负责）

自检回答的是「有没有按要求输出」，**不回答「内容是不是真的」**。以下必须由人过一遍：

- [ ] **事实**：结论有没有原始材料支撑？有没有把推测写成事实？
- [ ] **数字 / 日期**：逐个回查来源，包括百分比、金额、时长、名次。
- [ ] **引用 / 链接**：原文是否一致？链接能否打开？
- [ ] **专有名词**：人名、机构、产品名、术语有没有写错或张冠李戴。
- [ ] **表达**：有没有不符合受众的语气、不该出现的内部说法、冒犯性表述。
- [ ] **行动项**：结尾给的行动是否具体、可执行、真的属于这个任务。
- [ ] **合规**：涉及他人材料、肖像、版权、数据时，授权与出处是否齐备。
- [ ] **留白**：所有「待核实」「待补充」是否都已补上或明确放弃。

---

## 边界规则

1. **自检最多一次**。第二次起先问「这次改的是哪一条限制」，避免无限打磨第一版。
2. **自检不覆盖事实**。模型无法验证自己生成的数字，也不能验证引用是否真实存在。
3. **不把「已自检」写成质量保证**。交付时如实写「已按任务卡自检一次，事实项仍需人工核查」。
4. **用户只要结果时**，仍附一行人工核查提示，不展开全流程。

---

## 记录模板

```
交付记录
- 本轮任务：……
- 任务卡校验：通过 / 未通过（原因）
- 自检：通过 N 项，修正 M 项，修订 1 次
- 待人工确认：① …… ② ……
- 下一轮：……（未收敛的其他目标）
```
