# 限制要能落地

口播里最值钱的一句：**「更美观」「更准确」这类词 AI 并不懂，它只会自己猜什么叫更美观，然后给出一个它认为正确的答案。所以要给能落地的动词。**

本文件把这句经验变成可判定的规则。

---

## 判定标准：至少满足一条

一条限制算「能落地」，必须满足以下至少一条：

| 标准 | 含义 | 例子 |
| --- | --- | --- |
| 可观察 | 结果里能直接看见有没有 | 开头第一个字是「你」；不出现英文缩写 |
| 可测量 | 能数、能比大小 | 每句不超过 20 字；共 3 个章节 |
| 有参照物 | 指向一个具体对象 | 配色与参考图 A 一致；语气照样例第 2 段 |
| 有验收动作 | 说清怎么检查 | 每个数字后标注来源，无法确认就写「待核实」 |

**一句话测试**：把这条限制和成果给两个不同的人，他们会不会对「是否达标」给出同一个答案？会，就合格；不会，就还是形容词。

反过来，凡是「更 X」「X 一点」「尽量 X」「差不多」「看着办」「有质感」「高大上」「专业一些」，一律判不合格。

---

## 口播原例

> 想要生成的东西更美观一点、更准确一点，AI 其实都不明白。

改写成：

- 视觉与随附示例图的配色、字号层级保持一致
- 或：参考《星月夜》的深蓝底与明黄笔触，配色不超过 4 色

注意第二种仍然可以更具体：把「梵高的油画风格」拆成可观察的配色数和笔触特征。指向具体作品、具体元素，比指向一位画家稳定得多。

## 模糊写法 → 落地改写对照表

| 模糊写法 | 为什么不行 | 落地改写 |
| --- | --- | --- |
| 更美观 / 好看一点 | 审美无共识 | 与参考图 A 的配色、字号层级一致，不新增色值 |
| 更高级 / 有质感 | 感受词 | 只用黑白灰三色，去掉渐变与投影 |
| 更准确 | 无验收口径 | 每个数字后标注来源；无法确定写「待核实」 |
| 更简洁 | 无长度 | 全文不超过 200 字，删掉所有形容词 |
| 更口语 | 无标准 | 每句不超过 20 字，不用「因此、然而、综上所述」 |
| 专业一点 | 人群与语域不清 | 使用术语表内 5 个词，不出现网络用语 |
| 要有爆款感 | 结果不可控 | 标题以「你」开头，前 3 秒出现一个具体数字 |
| 尽量快 | 无口径 | 直接给结果，不解释推理过程 |
| 大概三页 | 边界模糊 | 3 个章节，每章 150 字左右，共 450 字 |
| 差不多就行 | 主动放弃验收 | 按任务卡第 3 节格式逐项打勾 |
| 适合年轻人 | 人群太宽 | 面向 18–24 岁在校生，不出现职场黑话 |
| 结构清晰 | 无结构定义 | 分「结论 / 依据 / 下一步」三段，每段一个小标题 |
| 语气亲切 | 不可观察 | 使用「你」，不用「您」；每段落不超过 2 句 |
| 别太长 | 无上限 | 总字数 ≤ 300，超出就删例子保留结论 |
| 排版舒服 | 不是格式要求 | 段间空一行，每段 ≤ 3 行，列表用短横线 |
| 内容丰富一点 | 与「简洁」常冲突 | 每个结论后补 1 条具体例子，共 3 条 |
| 逻辑通顺 | 无检查方式 | 每段首句为该段结论，段间不得重复同一论据 |
| 参考竞品 | 未指定对象 | 参考附件 B 的章节顺序，不复制其文案 |
| 自由发挥 | 与限制字段矛盾 | 明确写「本轮不设风格限制」，但格式与字数仍固定 |
| 信息要全 | 无法判定 | 覆盖任务卡背景中的 5 个要点，缺的标「待补充」 |

## 可用动词表

写限制时从下面挑开头，通常就不会飘：

**包含类**：包含、列出、逐条列出、覆盖、分为、附上、保留、注明、标注
**排除类**：排除、删除、不要、禁止、不出现、不使用、跳过
**边界类**：不超过、不少于、至少、至多、等于、限制在、控制在
**形态类**：以…开头、以…结尾、改成、替换成、对齐、保持…一致、采用、参照、参考
**验收类**：标注来源、写「待核实」、留空待确认、逐项打勾

对照动词表再读一遍自己写的限制：如果一条里一个这类词都没有，大概率还是愿望。

---

## 四个反模式

1. **把限制写成目标**：「要爆款」「要转化高」是结果，不是可执行动作。改成能做的动作。
2. **限制互相打架**：「内容丰富一点」+「不超过 100 字」。写完后通读一遍，冲突就让用户二选一。
3. **限制多到没有第一版**：十几条硬要求会让模型反复自我否定。3–6 条，剩下的第二轮加。
4. **用限制偷偷塞审美**：「配色克制一点」仍然是形容词。给色号、给色数、给参考图。

---

## 与「示例」字段的配合

限制负责划边界，示例负责定气质。当一条限制怎么写都像形容词时，最省事的解法往往不是继续打磨措辞，而是补一个具体参照物：

> 与其写「配色克制高级」，不如贴一张参考图，写「主色只用参考图的 #070708 与 #F5C451」。

这也是五要素里「示例」不可省的原因。
