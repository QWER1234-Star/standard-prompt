# 示例 02｜「更美观一点」→ 可验收的视觉 brief

**演示重点**：口播里的原例。把形容词换成参照物、色号和可数的上限。

口播原话是「把更美观换成视觉和示例一致，或视觉参考梵高的油画风格」。这里再往前走一步：把「一位画家」拆成具体作品、具体配色数和具体元素，因为指向一位画家仍然会被模型自由解释。

## 原始请求

> 把这个页面弄得更美观一点、更准确一点。

问题：两个词都没有验收口径；「准确」在这里指什么也没说。

## 1. 任务

把落地页首屏的配色与标题层级改写成一份视觉 brief，用于交给设计执行。

## 2. 背景

- 附件 A：一张深色底、单一强调色的参考图。
- 现有页面：带渐变与投影，标题层级 4 级，主色 6 种。
- 受众：18 至 24 岁在校用户；使用场景是手机竖屏首屏。

## 3. 输出格式

Markdown 表格，2 列（项目 / 要求），共 6 行；表格下方附一句验收方法；总字数不超过 200。

## 4. 限制

- 参照附件 A 的配色关系与字号层级，不新增色值。
- 主色只使用 #070708 与 #F5C451，辅助文字用白色降低不透明度。
- 删除全部渐变与投影。
- 配色不超过 4 色，标题层级保持 3 级。
- 不出现描述性的风格词，改为标注色号或给出参照物。
- 每个数字标注来源，无法确认就写「待核实」并问我。

## 5. 示例

附件 A（深色底 + 单一强调色的参考图）。参照它的「深底 + 一个亮色只用在编号和高亮词」这一关系，不复制其文字内容。

## 套用句（可直接复制）

```
我要完成【把落地页首屏的配色与标题层级改写成一份视觉 brief，用于交给设计执行】。
背景材料：【附件 A + 现有页面描述 + 受众说明】。
输出格式：【2 列 6 行 Markdown 表格，附一句验收方法，总字数不超过 200】。
限制：【参照附件 A；主色只用两个色值；删除渐变与投影；配色不超过 4 色；层级保持 3 级；不出现风格词；数字标注来源】。
参考示例：【附件 A，参照深底加单一强调色的关系】。
信息不够就问我，不要编造。
```

## 第一版结果

| 项目 | 要求 |
| --- | --- |
| 背景色 | #070708 |
| 强调色 | #F5C451，只用于编号与标题高亮词 |
| 文字色 | #F5F5F7，次级文字降低不透明度 |
| 色值上限 | 不超过 4 色 |
| 标题层级 | 保持 3 级，删除第 4 级 |
| 效果处理 | 删除全部渐变与投影 |

验收方法：打开成品逐项对照表格打勾，两项不同人应得出同一结论。

## 人工核查清单
