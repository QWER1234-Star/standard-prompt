# 示例 01｜零散笔记 → 60 秒口播稿

**演示重点**：把「写好一点」拆成可打勾的限制；自检真的查出一项不合格并修订一次。

## 原始请求

> 帮我把这段笔记整理成口播稿，写好一点，适合发抖音。

问题：没有受众、没有篇幅、没有验收标准，「写好一点」无法判定。

## 1. 任务

把下面 3 条零散笔记变成一条 60 秒口播稿，用于抖音发布。

## 2. 背景

原始材料（原文粘贴，不改写）：

- 笔记 1：AI 工具收藏了一堆，真到用的时候还是不知道从哪开始。
- 笔记 2：顺序比工具重要，先定任务，再给材料，最后检查。
- 笔记 3：第一版不用完美，先能被人挑毛病就行。

受众：收藏过很多 AI 教程、但一次都没真正用起来的在校学生。他们已知「AI 能写东西」，不知道「该从哪一步开始」。

## 3. 输出格式

Markdown；正文 8 句，每句单独一行；末尾另起一行写「行动：……」；总字数 200 至 260。

## 4. 限制

- 以「你」字开头，不使用「大家好」。
- 每句不超过 20 字，不使用「因此、然而、综上所述」。
- 包含 3 个编号步骤，分别对应三条笔记的要点。
- 不出现具体产品名与工具名。
- 以一句可执行的行动结尾，并写明「下一条做给你看」。
- 不新增笔记里没有的数字与案例，缺信息就写「待核实」并问我。

## 5. 示例

合格开头样例：「你收藏了几十个 AI 教程，真到用的时候，还是不知道从哪开始，对吧？」

参照它的第二人称与疑问句节奏，不照抄内容。

## 套用句（可直接复制）

```
我要完成【把 3 条零散笔记变成 60 秒口播稿，用于抖音发布】。
背景材料：【粘贴上方 3 条笔记 + 受众说明】。
输出格式：【8 句，每句一行，末尾单列行动，总字数 200 至 260】。
限制：【以「你」开头；每句不超过 20 字；包含 3 个编号步骤；不出现工具名；以可执行行动结尾；不新增数字】。
参考示例：【上方合格开头样例，参照其第二人称与疑问句节奏】。
信息不够就问我，不要编造。
```

## 第一版结果

你收藏了几十个教程，真到用的时候还是不知道从哪开始。
先别急着挑工具，你缺的不是工具，是顺序。
第一，写下今天真要完成的一件小事。
第二，把任务、背景、格式、限制、示例一次给齐。
第三，拿到结果先查一遍，再让它改一次。
限制要写成能打勾的动作，别写成愿望。
第一版不用完美，能被人挑毛病就够了。
AI 不是替你思考，是帮你更快做出第一版。

行动：下一条，我拿一个真实任务做给你看。

## 自检记录

```
自检记录
[OK] 任务：只交付口播稿，未顺带写分镜或标题
[OK] 背景：未引入笔记之外的事实
[!!] 格式：第 2 句 23 字，超出 20 字上限，压缩为「先别挑工具，你缺的是顺序。」
[OK] 限制 1、3、4、5、6：全部满足
[!!] 限制 2：压缩后 17 字，满足
[OK] 示例：第二人称与疑问句节奏一致，未照抄
[OK] 未编造：无未标注来源的数字
修订：1 次
```

注意自检只回答「有没有按任务卡输出」，不回答「内容是不是真的」。

## 人工核查清单

- [ ] 「几十个教程」是修辞还是可核查数字？保留还是改成「一堆」？
- [ ] 三条编号步骤是否与笔记原文的顺序一致，有没有偷偷加进第四条？
- [ ] 结尾承诺的「下一条做给你看」是否真的会兑现——这是账号信誉，不是文案问题。
- [ ] 有没有出现不该出现的工具名或平台名？
